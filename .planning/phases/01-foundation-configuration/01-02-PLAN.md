**Config-First Initialization Pattern (from ARCHITECTURE.md):**
```clojure
(defn load-config! []
  (let [config-file (io/file (System/getenv "HOME") ".config/ok-voice/config.yaml")]
    (when-not (.exists config-file)
      (notify/error "Config not found" "Create ~/.config/ok-voice/config.yaml")
      (System/exit 1))
    (let [cfg (yaml/parse-string (slurp config-file))]
      (when-not (:api-key cfg)
        (notify/error "Missing API key" "Add api-key to config.yaml or set OPENAI_API_KEY")
        (System/exit 1))
      cfg)))
```
