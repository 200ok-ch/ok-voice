# Key Context from Research

**Audio format requirement (from RESEARCH.md):**
- PCM16: 16-bit signed little-endian
- Sample rate: 24000 Hz
- Channels: 1 (mono)
- pw-record command: `pw-record --raw --rate=24000 --channels=1 --format=s16 -`

**Chunk size calculation:**
- 1 sample = 2 bytes (16-bit)
- 24000 samples/second = 48000 bytes/second
- 100ms chunk = 4800 bytes raw → ~6400 bytes base64
- 100ms is recommended chunk duration for responsive VAD

**Base64 encoding (JVM standard):**
```clojure
(def encoder (java.util.Base64/getEncoder))
(defn encode-base64 [^bytes ba]
  (.encodeToString encoder ba))
```

**Process management (babashka.process):**
```clojure
(def audio-proc
  (p/process ["pw-record" "--raw" "--rate=24000" "--channels=1" "--format=s16" "-"]
             {:out :stream :err :inherit}))
;; Read from (:out audio-proc) which is java.io.InputStream
;; Stop with (p/destroy-tree audio-proc)
```

   - If fewer bytes available (stream ending), reads what's available

   - Base64-encodes the raw bytes
   - Returns the base64 string, or nil if stream is closed

7. Function `(stream-chunks! [audio-proc callback])` that:
   - Loops calling read-chunk
   - For each non-nil chunk, calls `(callback base64-chunk)`
   - Exits loop when read-chunk returns nil (stream closed)
   - Catches IOException (stream closed by destroy-tree) and exits cleanly
   - Returns nil when done
   - This function blocks — caller should run it in a future

Implementation pattern for read-chunk:
```clojure
(defn read-chunk [audio-proc]
  (let [buf (byte-array chunk-size)
        in ^java.io.InputStream (:out audio-proc)
        n (.read in buf)]
    (when (pos? n)
      (let [chunk (if (= n chunk-size)
                    buf
                    (java.util.Arrays/copyOf buf n))]
        (encode-base64 chunk)))))
```

Implementation pattern for stream-chunks!:
```clojure
(defn stream-chunks! [audio-proc callback]
  (try
    (loop []
      (when-let [chunk (read-chunk audio-proc)]
        (callback chunk)
        (recur)))
    (catch java.io.IOException _
      nil)))
```
