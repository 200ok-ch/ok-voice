# Key Context from Research

**WebSocket URL and headers:**
- URL: `wss://api.openai.com/v1/realtime?intent=transcription`
- Headers: `Authorization: Bearer <API_KEY>`, `OpenAI-Beta: realtime=v1`

**Session configuration (sent after session.created):**
```json
{
  "type": "session.update",
  "session": {
    "type": "transcription",
    "input_audio_format": "pcm16",
    "input_audio_noise_reduction": {"type": "near_field"},
    "input_audio_transcription": {
      "model": "gpt-4o-mini-transcribe"
    },
    "turn_detection": {
      "type": "server_vad",
      "threshold": 0.5,
      "prefix_padding_ms": 300,
      "silence_duration_ms": 500
    }
  }
}
```
Note: Omit "language" field from input_audio_transcription to enable auto-detection (CORE-05).

**CRITICAL: Message fragment accumulation:**
The babashka.http-client.websocket on-message callback wraps java.net.http.WebSocket.Listener.
A single logical JSON message may arrive across multiple on-message calls.
The `last?` parameter indicates whether the current fragment completes the message.
MUST accumulate in a StringBuilder until last? is true, then parse JSON.

**Client→Server events needed:**
- `session.update` — Configure transcription session (sent once after session.created)
- `input_audio_buffer.append` — Send base64 audio chunk (sent continuously)

**Server→Client events to dispatch:**
- `session.created` — Connection established, trigger session config
- `session.updated` — Session configured successfully
- `input_audio_buffer.speech_started` — VAD detected speech
- `input_audio_buffer.speech_stopped` — VAD detected silence
- `conversation.item.input_audio_transcription.delta` — Streaming transcription text
- `conversation.item.input_audio_transcription.completed` — Final transcript for utterance
- `conversation.item.input_audio_transcription.failed` — Transcription failed
- `error` — API error

**babashka.http-client.websocket API:**
```clojure
(ws/websocket {:uri url :headers headers
               :on-open fn :on-message fn :on-close fn :on-error fn})
(ws/send! ws json-string)
(ws/close! ws 1000 "done")
```

   - On "session.created": sends session-config as JSON via `(ws/send! ws (json/generate-string (session-config)))`
   - On "session.updated": calls (:on-ready handlers) if present
   - On "conversation.item.input_audio_transcription.delta": calls (:on-delta handlers) with (:delta event)
   - On "conversation.item.input_audio_transcription.completed": calls (:on-completed handlers) with (:transcript event)
   - On "input_audio_buffer.speech_started": calls (:on-speech-started handlers) if present
   - On "input_audio_buffer.speech_stopped": calls (:on-speech-stopped handlers) if present
   - On "conversation.item.input_audio_transcription.failed": calls (:on-error handlers) with error message
   - On "error": calls (:on-error handlers) with error message, also calls notify/error

5. Function `(connect! [api-key handlers])` that:
   - `handlers` is a map of callback functions:
     - `:on-ready` — called when session is configured and ready for audio (no args)
     - `:on-delta` — called with delta text string
     - `:on-completed` — called with final transcript string
     - `:on-speech-started` — called when VAD detects speech (no args)
     - `:on-speech-stopped` — called when VAD detects silence (no args)
     - `:on-error` — called with error message string
     - `:on-close` — called when WebSocket closes (no args)
   - Creates a **per-connection** message fragment buffer: `(let [msg-buf (atom (StringBuilder.))] ...)`
     This buffer is scoped inside connect!, NOT at the module level, so each connection gets its own buffer.
   - Creates WebSocket connection with:
     - `:uri` api-url
     - `:headers` with Authorization Bearer and OpenAI-Beta headers
     - `:on-open` logs connection
     - `:on-message` accumulates fragments into the per-connection msg-buf, parses JSON when last? is true, dispatches event
     - `:on-close` calls (:on-close handlers) if present
     - `:on-error` calls (:on-error handlers) with error message
   - Returns the WebSocket object

   - Serializes to JSON with `json/generate-string`: `(json/generate-string {"type" "input_audio_buffer.append" "audio" base64-chunk})`
   - Sends the JSON string via `(ws/send! ws json-str)`

7. Function `(close! [ws])` that:
   - Calls `(ws/close! ws 1000 "done")`

Key implementation detail for on-message (note: msg-buf is created per-connection inside connect!):
```clojure
(let [msg-buf (atom (StringBuilder.))]
  ...
  :on-message (fn [ws data last?]
                (.append @msg-buf data)
                (when last?
                  (let [full (str @msg-buf)]
                    (reset! msg-buf (StringBuilder.))
                    (let [event (json/parse-string full true)]
                      (dispatch-event ws event handlers)))))
  ...)
```
