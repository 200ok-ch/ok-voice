# Key Context

**Toggle pattern:**
- xbindkeys calls `bb -m ok-voice.core` on each hotkey press
- First press: no instance running → start recording
- Second press: instance running → signal stop via SIGTERM
- JVM shutdown hooks (already in core.clj) handle cleanup on SIGTERM

**PID file location:**
- Primary: `$XDG_RUNTIME_DIR/ok-voice.pid` (typically `/run/user/<uid>`)
- Fallback: `/tmp/ok-voice.pid`
- XDG_RUNTIME_DIR is per-user, cleaned on logout — ideal for PID files

**Getting PID in babashka:**
- `ProcessHandle` is NOT available in babashka (GraalVM native image limitation)
- Use: `(parse-long (clojure.string/trim (:out (babashka.process/sh "sh" "-c" "echo $PPID"))))`
- `$PPID` inside spawned shell = parent PID = babashka's PID (verified)

**Process alive check:**
- `kill -0 <pid>` returns exit 0 if process exists, non-zero otherwise
- Does not actually send a signal — just checks existence

**Signaling:**
- `kill <pid>` sends SIGTERM (default signal)
- JVM catches SIGTERM and runs shutdown hooks before exit
- Shutdown hooks in core.clj already stop the pipeline and clean up

# Dependencies from Phase 2
- babashka.process (built into bb, no extra dep)
- core.clj has shutdown hook that stops pipeline on SIGTERM

Create src/ok_voice/toggle.clj with:

1. Namespace:
   ```clojure
   (ns ok-voice.toggle
     (:require [babashka.process :as p]

               [clojure.string :as str]))
   ```

2. PID file path:
   ```clojure
   (def ^:private pid-path
     (str (or (System/getenv "XDG_RUNTIME_DIR") "/tmp")
          "/ok-voice.pid"))
   ```

3. Function `(current-pid [])` — private helper:
   - Gets current babashka process PID
   - Implementation: `(parse-long (str/trim (:out (p/sh "sh" "-c" "echo $PPID"))))`
   - Returns long PID

4. Function `(write-pid! [])` that:
   - Gets current PID via `(current-pid)`
   - Writes it to pid-path via `(spit pid-path (str pid))`
   - Returns nil

5. Function `(read-pid [])` that:
   - Checks if PID file exists
   - If exists, reads and parses content as long
   - Returns integer PID or nil (if file missing, empty, or unparseable)
   - Wraps in try/catch for robustness

6. Function `(remove-pid! [])` that:
   - Deletes PID file if it exists via `(.delete (io/file pid-path))`
   - Returns nil
   - Safe to call when file doesn't exist

7. Function `(process-alive? [pid])` that:
   - Runs `kill -0 <pid>` via `(p/sh "kill" "-0" (str pid))`
   - Returns true if exit code is 0 (process exists)
   - Returns false on any exception or non-zero exit
   - Wraps in try/catch for robustness

8. Function `(running-instance [])` that:
   - Calls `(read-pid)` to get PID from file
   - If nil, returns nil (no PID file)
   - If PID found, checks `(process-alive? pid)`
   - If alive, returns the PID
   - If dead (stale PID file), calls `(remove-pid!)` and returns nil

9. Function `(signal-stop! [pid])` that:
   - Sends SIGTERM: `(p/sh "kill" (str pid))`
   - Returns nil

Do NOT add:
- File locking (race window is negligible for hotkey use case)
- Custom signal handling (SIGTERM + JVM shutdown hooks suffice)
- Notification logic (core.clj handles that)
- Any toggle orchestration logic (that's plan 03-02)
