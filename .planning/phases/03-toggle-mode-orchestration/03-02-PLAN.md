# Current core.clj behavior (Phase 2)
- deps/check! → config/load! → validate-api-key! → start pipeline → block forever
- Shutdown hook: stop pipeline, print transcription text
- No toggle awareness — always starts recording

# New behavior (Phase 3)
Two execution paths based on singleton detection:

**Path A — Stop (instance running):**
1. `(toggle/running-instance)` returns PID
2. Send SIGTERM to existing instance: `(toggle/signal-stop! pid)`
3. Exit 0 immediately
4. Skip deps check, config loading, everything — just signal and exit

**Path B — Start (no instance running):**
1. `(toggle/running-instance)` returns nil
2. `(deps/check!)` — validate dependencies
3. `(config/load!)` → `(config/validate-api-key!)` — load API key
4. `(toggle/write-pid!)` — claim singleton
5. `(notify/info "ok-voice" "Recording started...")` — user feedback
6. `(transcription/start! api-key)` — start pipeline
7. If pipeline fails: `(toggle/remove-pid!)`, exit 1
8. Register shutdown hook, block forever

**Shutdown hook (updated):**
1. `(toggle/remove-pid!)` — release singleton FIRST (minimizes race window)
2. `(transcription/stop! pipeline)` — stop audio + WebSocket
3. Get and print transcription text
4. `(notify/info "ok-voice" "Recording stopped.")` — user feedback

# Why toggle check comes first
- Stop path must be fast — no config loading or dep checking needed
- Avoids error notifications when just trying to stop recording
- User expects immediate response to hotkey press

# Race condition analysis
- Rapid double-press: second invocation arrives while first is still starting
  - If first hasn't written PID yet: both try to start → second will overwrite PID
  - Mitigation: PID write happens before pipeline start, narrowing the window
  - Practical impact: negligible — bb startup is ~100ms, key debounce is ~50ms
- Rapid triple-press: third arrives while first is shutting down
  - If PID already removed: starts new recording (correct behavior)
  - If PID still present: sends SIGTERM to dying process (harmless)

   ```clojure
   (defn -main [& args]
     ;; Toggle check first — fast path for "stop" case
     (if-let [pid (toggle/running-instance)]
       ;; Instance running → signal stop and exit
       (do
         (toggle/signal-stop! pid)
         (System/exit 0))
       ;; No instance → start recording
       (do
         (deps/check!)
         (let [cfg (config/load!)
               api-key (config/validate-api-key! cfg)]
           (toggle/write-pid!)
           (notify/info "ok-voice" "Recording started...")
           (let [pipeline (transcription/start! api-key)]
             (when-not pipeline
               (toggle/remove-pid!)
               (System/exit 1))
             (.addShutdownHook (Runtime/getRuntime)
               (Thread. (fn []
                          (toggle/remove-pid!)
                          (transcription/stop! pipeline)
                          (let [text (transcription/get-text)]
                            (when (seq text)
                              (println)
                              (println "--- Transcription ---")
                              (println text)))
                          (notify/info "ok-voice" "Recording stopped."))))
             (deref (promise)))))))
   ```

3. Keep the `(-main)` call at the bottom for bb -m execution.
