# Why clipboard paste instead of xdotool type

`xdotool type` simulates individual keystrokes via XTest. Characters not in the current
X11 keymap are silently dropped. Since ok-voice auto-detects language (CORE-05), users
will speak in languages with non-Latin characters (umlauts, CJK, Cyrillic, etc.).

Clipboard paste (xclip + xdotool key ctrl+v) is encoding-aware and handles all Unicode
reliably. The trade-off of overwriting the clipboard is acceptable — the transcribed text
in the clipboard is actually useful for re-pasting.

```clojure
(ns ok-voice.text
  (:require [babashka.process :as p]))

(defn insert-at-cursor!
  "Inserts text at cursor position via clipboard paste.
   Sets X11 clipboard via xclip, then simulates ctrl+v via xdotool."
  [text]
  (when (and text (seq (str text)))
    (p/sh {:in (str text)} "xclip" "-selection" "clipboard")
    (Thread/sleep 50)
    (p/sh "xdotool" "key" "--clearmodifiers" "ctrl+v")
    nil))
```
